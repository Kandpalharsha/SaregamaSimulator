  Sa Re Ga Ma Harmonium Simulator (Java + Swing)

A simple desktop application built in Java using Swing that simulates the Indian musical scale "Sa Re Ga Ma Pa Dha Ni Sa" (C major scale equivalent). This tool allows you to play notes using your keyboard or on-screen buttons — just like a basic harmonium or piano!
 Features->
  Play Indian Notes: Sa, Re, Ga, Ma, Pa, Dha, Ni, Sa
  Keyboard Mapping:  
  - `A` = Sa (C)  
  - `S` = Re (D)  
  - `D` = Ga (E)  
  - `F` = Ma (F)  
  - `G` = Pa (G)  
  - `H` = Dha (A)  
  - `J` = Ni (B)  
  - `K` = Sa' (High C)
  Mouse Support: Click buttons to play notes.
  Visual Feedback: Keys light up when pressed.
  Real-Time Audio Generation: Pure sine wave tone synthesis using Java Sound API.
  Exit Option: Press `L` or click Exit to close the app.
